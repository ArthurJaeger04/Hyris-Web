# Hyris Web

Plataforma Full Stack desenvolvida para integração entre website e infraestrutura de um servidor multiplayer online, centralizando estatísticas, rankings, e-commerce digital, métricas administrativas e gerenciamento operacional.

> O código-fonte deste projeto não está disponível publicamente devido a diretrizes internas da comunidade e à presença de informações proprietárias. Este repositório existe exclusivamente para apresentação técnica do projeto.

## Funcionalidades

### Portal Principal

* Exibição do status do servidor em tempo real.
* Quantidade de jogadores online.
* Informações de versão do servidor.
* Página institucional da equipe.
* Sistema de consulta de jogadores.
* Estatísticas detalhadas dos minigames.
* Consulta pública de punições.
* Histórico de bans e mutes.
* Exibição de datas e expirações das punições.

### Sistema de Leaderboard

* Ranking global por minigame.
* Visualização dos Top 10 jogadores.
* Visualização expandida para Top 100 jogadores.
* Exibição de nickname, cargo e estatísticas.
* Atualização automática baseada nos dados do servidor.

### Loja Virtual

* Venda de ranks VIP.
* Venda de tags exclusivas.
* Venda de serviços personalizados.
* Sistema de cupons.
* Integração completa com Stripe.
* Aplicação automática dos produtos após aprovação do pagamento.

### Serviços Personalizados

* Migração de contas.
* Solicitação de reversão de banimento.
* Solicitação de reversão de mute.
* Outros serviços administrativos personalizados.

### Dashboard Administrativo

* Gerenciamento de produtos.
* Cadastro e atualização da loja.
* Atualização de conteúdos sem alteração de código.
* Ferramentas operacionais da equipe.

### MMS (Moderation Management System)

* Estatísticas individuais da equipe.
* Histórico de banimentos.
* Histórico de punições.
* Métricas por período.
* Relatórios de desempenho.
* Monitoramento operacional da moderação.
